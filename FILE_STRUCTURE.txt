DATABASE TABLES (db_schema.xml)
==============================

1. marrso_pickup_location (Pickup Point Locations)
   - entity_id (PK, INT)
   - name (VARCHAR 255)
   - code (VARCHAR 100, UNIQUE)
   - address (TEXT)
   - district (VARCHAR 100)
   - latitude (DECIMAL 10,8)
   - longitude (DECIMAL 11,8)
   - priority (INT)
   - is_active (BOOLEAN)
   - created_at (TIMESTAMP)
   - updated_at (TIMESTAMP)
   ├─ INDEX: code
   ├─ INDEX: district
   └─ INDEX: is_active

2. marrso_pickup_slot (Pickup Time Slots)
   - entity_id (PK, INT)
   - pickup_location_id (FK, INT)
   - slot_date (DATE)
   - start_time (TIME)
   - end_time (TIME)
   - capacity (INT)
   - used_capacity (INT)
   - is_active (BOOLEAN)
   - created_at (TIMESTAMP)
   - updated_at (TIMESTAMP)
   ├─ FK: pickup_location_id → marrso_pickup_location
   ├─ INDEX: pickup_location_id
   └─ INDEX: slot_date

3. marrso_delivery_slot (Home Delivery Slots)
   - entity_id (PK, INT)
   - district (VARCHAR 100)
   - slot_date (DATE)
   - start_time (TIME)
   - end_time (TIME)
   - price (DECIMAL 12,2)
   - capacity (INT)
   - used_capacity (INT)
   - carrier_code (VARCHAR 50)
   - is_active (BOOLEAN)
   - created_at (TIMESTAMP)
   - updated_at (TIMESTAMP)
   ├─ INDEX: district
   ├─ INDEX: slot_date
   └─ INDEX: is_active

4. marrso_delivery_holiday (Non-Operating Dates)
   - entity_id (PK, INT)
   - holiday_date (DATE, UNIQUE)
   - description (VARCHAR 255)
   - created_at (TIMESTAMP)
   - updated_at (TIMESTAMP)
   └─ INDEX: holiday_date

5. marrso_order_delivery_schedule (Order Selection Persistence)
   - entity_id (PK, INT)
   - order_id (FK, INT, UNIQUE)
   - quote_id (INT)
   - delivery_type (ENUM: 'pickup', 'delivery')
   - pickup_location_id (INT)
   - delivery_date (DATE)
   - delivery_slot (VARCHAR 100)
   - customer_comment (TEXT)
   - created_at (TIMESTAMP)
   - updated_at (TIMESTAMP)
   ├─ FK: order_id → sales_order
   ├─ INDEX: order_id
   └─ INDEX: quote_id


API ENDPOINTS (webapi.xml)
==========================

CUSTOMER ENDPOINTS:
GET    /V1/delivery/pickup-locations          Get available pickups
GET    /V1/delivery/delivery-slots            Get available delivery slots
POST   /V1/delivery/save                      Save delivery selection

ADMIN ENDPOINTS:
GET    /V1/pickup-locations                   List all locations
POST   /V1/pickup-locations                   Create location
GET    /V1/pickup-locations/:id               Get location
PUT    /V1/pickup-locations/:id               Update location
DELETE /V1/pickup-locations/:id               Delete location

GET    /V1/pickup-slots                       List all pickup slots
POST   /V1/pickup-slots                       Create pickup slot
GET    /V1/pickup-slots/:id                   Get pickup slot
PUT    /V1/pickup-slots/:id                   Update pickup slot
DELETE /V1/pickup-slots/:id                   Delete pickup slot

GET    /V1/delivery-slots                     List all delivery slots
POST   /V1/delivery-slots                     Create delivery slot
GET    /V1/delivery-slots/:id                 Get delivery slot
PUT    /V1/delivery-slots/:id                 Update delivery slot
DELETE /V1/delivery-slots/:id                 Delete delivery slot

GET    /V1/delivery-holidays                  List all holidays
POST   /V1/delivery-holidays                  Create holiday
GET    /V1/delivery-holidays/:id              Get holiday
DELETE /V1/delivery-holidays/:id              Delete holiday

GET    /V1/order-delivery-schedules           List all schedules
GET    /V1/order-delivery-schedules/:id       Get schedule
GET    /V1/order-delivery-schedules/order/:id Get order schedule
